
# ALU Machine Learning Coaching — Pre-Session

**Topic:** Tabular Q-Learning  
**Duration:** 15 minutes  
**Format:** Independent, interactive preparation

## Welcome

Welcome to the pre-session activity for the ALU Software Engineering Specialisation Coach (Machine Learning) mock session.

This activity introduces the fundamental concepts of Tabular Q-Learning and prepares participants for the live coaching session.

## Launch the Pre-Session Notebook

### [▶ Open Pre-Session Notebook in Google Colab](https://colab.research.google.com/github/JNUgwu/alu-ml-qlearning-coaching/blob/main/01_Pre_Session/ALU_RL_Pre_Session_Interactive_Guide.ipynb)

**Open in a new tab:** Hold `Ctrl` (Windows/Linux) or `Command` (Mac) while clicking the link. Alternatively, right-click and select **Open Link in New Tab**.

## Learning Objectives

By completing this preparation activity, participants should be able to:

1. Describe the basic idea of reinforcement learning.
2. Identify the roles of states, actions and rewards.
3. Recognise the purpose of a Q-table.
4. Explain why an agent needs to balance exploration and exploitation.

## Instructions

1. Open the notebook using the link above.
2. Read the introductory explanations.
3. Run the provided Python examples.
4. Observe the outputs and answer the preparation questions.
5. Record any observations or questions for the live coaching session.

**Note:** You do not need to install Python locally. The notebook runs in Google Colab.

## Next Step

After completing this activity, proceed to the [Live Coaching Session](https://github.com/JNUgwu/alu-ml-qlearning-coaching/tree/main/02_Live_Coaching) when instructed by the facilitator.
